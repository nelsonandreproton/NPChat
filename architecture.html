NPChat

Purpose: Enterprise RAG (Retrieval-Augmented Generation) chatbot using local LLMs via Ollama and ChromaDB. Features hybrid semantic+BM25 search, HyDE (Hypothetical Document Embeddings), query expansion, response caching, and automatic feedback learning.
PythonFastAPIStreamlitOllamaChromaDBBM25SQLiteDocker

Architecture Overview

Key Workflows

RAG Query Pipeline
User query → FastAPI → cache check (hit: return cached response) → Query Expansion (generate 3 variants) → HyDE (generate hypothetical answer for embedding) → Hybrid retrieval (ChromaDB semantic + BM25 keyword, RRF fusion) → re-rank top-k chunks → Ollama LLM generates answer → quality auto-evaluation → cache response → return to UI.
Document Ingestion
Upload PDF/DOCX/TXT → chunking with overlap → embed via Ollama embeddings → store in ChromaDB vector store → BM25 index updated.
Feedback Learning
User rates response → feedback stored in SQLite → negative feedback triggers retrieval parameter adjustment → system automatically improves recall over time.
