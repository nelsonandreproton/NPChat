1. What this project does

Purpose

RAG chatbot answering questions about Near Partner using entirely local infrastructure. Scrapes nearpartner.com, chunks and embeds content, then uses hybrid semantic+BM25 retrieval (Reciprocal Rank Fusion), optional HyDE query expansion, and caches responses. Feedback from users automatically boosts/penalizes chunk scores.

3. API endpoints

POST/api/v1/chat
Send message, returns answer with source chunks. Body: {message, top_k, temperature, conversation_history}
POST/api/v1/feedback
Submit 👍/👎 rating for a response. Triggers chunk score adjustment and optional cache invalidation.
GET/api/v1/health
Liveness check — confirms the llama.cpp server is reachable and the ChromaDB collection exists.
GET/api/v1/stats
Query volume, cache hit rate, feedback summary, average confidence score.
